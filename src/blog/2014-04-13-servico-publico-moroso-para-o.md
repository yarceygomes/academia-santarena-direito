Para o contribuinte santareno conseguir uma simples certidão negativa tributária municipal ele precisa se dirigir a Prefeitura, formular expresso requerimento, juntar cópia de documentos pessoais, esperar pelo menos 5 dias para obter resposta do setor competente e, ao final, enfrentar novamente uma fila para receber o documento.</div>

<div>
